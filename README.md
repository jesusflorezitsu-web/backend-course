## Proyecto transversal

El `project/` es el **proyecto personal de fin de trimestre**: se mantiene reservado y
crecerá clase a clase. En la clase 3 el entregable usa su propia carpeta
`activities/class-03/project/` y en la clase 4 `activities/class-04/project/`
(ver sus `README.md`).

## Estructura

```txt
.
├── activities/
│   ├── class-01/          → Entrega 01
│   ├── class-02/          → Entrega 02
│   └── class-03/          → Entrega 03 (incluye project/ propio de la clase)
│   └── class-04/          → Entrega 04 (incluye project/ propio de la clase)
├── project/               → Proyecto personal de fin de trimestre (reservado)
└── resources-notes/       → Apuntes y lecturas
```

## Cómo ejecutar

Cada actividad trae sus propias instrucciones dentro de su `README.md`.
Requisito general: Node.js LTS (`node --version`).
